# 代码质量自查清单

提交前逐项勾选，并把行数和新增符号清单写入交付报告：

- [ ] 只改了任务点名的文件；没有顺手重构或增加未要求的行为。
- [ ] 每个函数不超过 60 行，逻辑嵌套不超过 3 层，圈复杂度不超过 15。
- [ ] 没有新增只用一次的抽象层；重复逻辑已抽取。
- [ ] 每个文件报告了净增行数；超过 500 行的文件净增为 0。
- [ ] 列出所有新增函数和 CSS 选择器；检查没有死代码。
- [ ] 新增第三方依赖已在提交说明写明理由；没有则注明“无”。
- [ ] `make quality` 通过；新增 CSS 没有 `!important`、字面颜色、超深嵌套或重复声明。
