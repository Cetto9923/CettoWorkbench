# 首页改版：PO 工作总览

用户确认：首页默认展示 PO 工作总览，个人紧急事项通过我的待办处理。

## 已实现的展示与交互调整

- 顶部保留简洁标题和两个真实入口：今日到期待办、我的待办。前者使用待办已支持的 focus=today，不带用其他集合统计的数字。
- 需求全景保留全部阶段及真实计数；点击阶段沿用现有后端分页与 URL 状态，不改变用户数据范围。
- 主列表保留 ID、事项、当前阶段、状态、当前负责人、详情。删除重复的“下一步=查看”，详情链接明确表示进入禅道，不伪装业务办理。
- 宽屏主列表与版本窗口并列，常用工作入口位于右侧；窄屏下侧栏移到列表之后。列表取消固定纵向滚动高度，保留窄屏水平滚动和完整分页。
- 移除未实现焦点按钮与 WAIT DECISION 弹窗；没有详情链接时显示普通文字，不提供假按钮。
- 增加当前列表刷新入口及请求忙碌状态。失败不显示零条，清除列表获取时间；保留重试、防乱序响应覆盖和共享分页。
- 首页不再加载 homecompact.css，布局收敛在现有 home.css；未修改全局公共样式。
