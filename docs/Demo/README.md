# PO 个人工作台 - PRD 静态演示 Demo 说明

本目录提取自当前已确定并验收通过的最新前端工程代码，所有后端接口均已适配本地静态 MOCK 数据，无需连接后端服务或数据库，可直接本地双击浏览器打开演示。

## 页面清单与文件入口

| 序号 | 页面模块 | 本地静态文件 | 功能特性与交互演示 |
|:---|:---|:---|:---|
| 1 | **PO 工作台首页** | [`home.html`](home.html) (或 [`index.html`](index.html)) | 顶部指标 Chips（今日必推/阻塞/超期/挂起）、10 阶段彩色价值全景流、业务需求行动列表（支持标题点击唤起需求详情抽屉）、右侧排期版本窗口概览。 |
| 2 | **我的待办** | [`todos.html`](todos.html) | 全部/业务需求/研发需求/任务/Bug/测试单多 Tab 切换；紧急度/截止时间状态；操作列办理跳转；纯静态 mock 列表渲染。 |
| 3 | **我的已办** | [`done.html`](done.html) | 操作对象快速定位与数量徽章标签；时间范围/关键词搜索；已办列表与已办记录详情抽屉联动。 |

## 技术说明

- **离线运行**：所有页面引用相对路径的 `css/`、`js/`、`vendor/` 静态资源（含 FontAwesome 图标、Quill 富文本等）。
- **Mock 机制**：内置 `js/mock-data.js`（全真数据字典与列表）与 `js/mock-service.js`，自动拦截浏览器的 `fetch` 与 `XMLHttpRequest` 请求，无需任何本地后端服务即可体验完整分页、筛选与抽屉滑出交互。
- **页面互通**：左侧统一导航栏、顶部快捷栏已全部绑定为相对静态页面链接，支持在 7 个核心页面间自由点击穿梭。
